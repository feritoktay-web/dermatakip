# DermaTakip

Dermokozmetik müşteri ve danışmanlık/işlem takibi için hazırlanmış, eczane ağına yönelik arayüz prototipi.

## İlk sürüm kapsamı

- Müşteri profili ve cilt tipi bilgisi
- Yapılan işlem, danışmanlık ve takip geçmişi
- Kontrol/randevu hatırlatma görünümü
- Stok takibi yoktur

## Yerelde açma

`index.html` dosyasını bir tarayıcıda açın. Bu prototip statik bir arayüzdür; eklenen müşteri geçici olarak tarayıcı oturumunda görünür.

## Canlı kullanıma geçiş notu

GitHub Pages, bu arayüzü yayınlamak için uygundur ancak müşteri kayıtlarını paylaşan güvenli bir veritabanı değildir. Eczane ağında ortak kullanım için bir sunucu uygulaması, erişim yetkileri, yedekleme ve KVKK uyumlu veri saklama katmanı eklenmelidir. Kişisel veya sağlık niteliğindeki müşteri verileri Git deposuna işlenmemelidir.
